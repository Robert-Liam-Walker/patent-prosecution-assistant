[DONE] 2. Global-corpus ingestion: 37 CFR fetcher
   scripts/ingest/fetch_cfr.ts via `npm run ingest:cfr`. Uses eCFR
   Versioner API: /titles to discover the latest issue date, then
   /full/<date>/title-37.xml?part=<n> per requested part. DIV8

   --clear-existing / --delay-ms. Verified live with §§ 1.111 / 1.112
   / 1.114 (2026-05-24); 9 chunks in Postgres.

[DONE] 3. Global-corpus ingestion: PTAB decisions fetcher
   scripts/ingest/fetch_ptab.ts via `npm run ingest:ptab`. Scrapes the
   USPTO precedential + informative decisions index, pairs each PDF link

   Paper N (PTAB) (precedential)". Flags: --designation / --filter /
   --limit / --dry-run / --clear-existing / --delay-ms. Verified live
   with 3 precedential decisions (2026-05-24); 82 chunks in Postgres.

[DONE-prompt / BLOCKED-model] 4b. Prosecution-grade strictness: ban "fully anticipated" overuse + inherency leaks
   Prompt side shipped in src/lib/prompts.ts:
     - Added "REJECTION / PRIOR-ART ANALYSIS — STRICT MODE" section that
       triggers when claim text is retrieved and the user mentions
       rejection / §102 / §103 / anticipation / obvious / prior art /
       office action.
     - Three-label discipline only: FULLY DISCLOSED / PARTIALLY
       DISCLOSED / NOT DISCLOSED. Banned: "fully anticipated",
       "essentially disclosed", "covers", "teaches the same".
     - Inherency banned without necessity showing — model must write
       "INHERENCY ARGUMENT — REQUIRES NECESSITY SHOWING NOT IN RECORD"
       and label NOT DISCLOSED.
     - Forbidden: critique not tied to a claim limitation (kills the
       "lacks GUI detail" failure mode).
     - INSUFFICIENT RETRIEVED SUPPORT gap-flag for un-judgeable
       limitations; no general-knowledge backfill.
     - Locator rule: only column/line/paragraph numbers that appear
       VERBATIM in retrieved text. Quote exactly. No invention.
     - Mandatory (A)–(E) output template (CLAIM BREAKDOWN /
       PRIOR ART MAPPING / §102 VERDICT / §103 ANALYSIS / CONCLUSION
       with consistency self-check).
   Verified (scripts/chat_e2e.ts, 3 iterations): on Llama 3.1 8B the
   locator-fabrication failure mode is FIXED (no more invented col/line
   refs). The 3-label discipline and (A)–(E) template are PARTIALLY
   honored — 8B still emits "fully anticipated" and skips template
   headers in most runs. This is a model-capacity ceiling, not a prompt
   bug. The prompt is correct for any capable model (Sonnet 4.6+ /
   Opus 4.7) and will compose cleanly with item 6 (citation /
   terminology post-pass) and item 9 (model upgrade). Marked
   DONE-prompt to record that the prompt change shipped; calibration
   gap remains until items 6 + 9. See memory `prompt-vs-model-ceiling`.

[DONE] 4d. Structured rejection analyzer via generateObject + Zod
   Shipped src/lib/analyze-rejection.ts. Flat Zod schema (nested
   schemas don't work on 8B — model invents its own shape and AI SDK
   repair pass can't recover). Disclosure is a union-coerced enum:
   anything other than literal "DISCLOSED" → "NOT_DISCLOSED" (preserves
   the binary discipline even if the model emits "PARTIALLY_DISCLOSED").
   SoftBool union handles missing or stringified booleans.
   nullish().transform() coerces undefined → default for optional
   string/array fields. Conclusion runs through scrubBannedTerms() to
   rewrite any "partial/fully anticipated" smuggled into prose.
   AI-SDK v6 gotcha: `mode: "json"` no longer exists; let the SDK
   auto-select. Another gotcha: z.undefined() in a union breaks JSON
   schema conversion ("Undefined cannot be represented in JSON Schema")
   — use .nullish() instead.
   Chat route detection (src/app/api/chat/route.ts): when query matches
   /rejection|§\s*10[23]|anticipat|obvious|prior art|office action/ AND
   retrieval includes case docs, route through analyzeRejection.
   Render via renderAnalysisMarkdown — (A)-(E) headers come from our
   code, not the model, so they're structurally guaranteed.
   Verified E2E (scripts/diag_generateobject.ts + scripts/chat_e2e.ts):
   structured output with binary verdicts, claim text quoted verbatim
   from claims2.txt, §102 NOT SATISFIED with failing limitation IDs
   listed. Residual 8B calibration noise (occasionally mis-labels a
   limitation or picks wrong evidence text) is unavoidable without
   items 9 or 10 — but the structural ground floor is now bulletproof.
   See memory `structured-output-pattern`.
